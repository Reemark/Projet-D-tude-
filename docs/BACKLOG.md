## Definition of Done (DoD)

Une user story est considérée "Done" quand :
- Le code est écrit, compilé et sans erreur
- Les tests associés passent
- Le code est reviewé et mergé
- La fonctionnalité est testable via Postman ou l'interface
- La documentation est à jour
